# NOTES

## Заплановано (не зараз)
- Друк етикеток через принтер Niimbot: поточний window.print() не бачить Niimbot на Mac,
  бо в нього немає стандартного драйвера — він працює через власний Bluetooth-протокол.
  Рішення: реалізувати пряме Bluetooth-з'єднання з принтером через Web Bluetooth API
  (орієнтир — відкритий проєкт niimblue: https://github.com/MultiMote/niimblue),
  замість системного діалогу друку. Дає справжній друк в один клік без вікна друку.
  Працює в Chromium-браузерах (Opera підходить), потребує окремої реалізації протоколу.
